Complete the square to write \(f(x) = 2x^2 - 12x + 7\) in vertex form. State the vertex and whether it is a maximum or a minimum.

Factor the 2 out of the first two terms only, then add and subtract \(\left(\tfrac{b}{2}\right)^2\) inside the bracket.
\(f(x) = 2(x-3)^2 - 11\). Vertex \((3, -11)\), a minimum.
  1. Factor 2 from the \(x\) terms: \(f(x) = 2(x^2 - 6x) + 7\).
  2. Half of \(-6\) is \(-3\); squared is \(9\). Add and subtract it inside: \(f(x) = 2(x^2 - 6x + 9 - 9) + 7\).
  3. Move the \(-9\) out. It gets multiplied by the 2 in front: \(f(x) = 2(x^2 - 6x + 9) - 18 + 7\).
  4. Write the perfect square and combine: \(f(x) = 2(x-3)^2 - 11\).
  5. \(a = 2 > 0\), so it opens up and the vertex \((3, -11)\) is a minimum.

Check it. The axis is \(x = -\tfrac{b}{2a} = \tfrac{12}{4} = 3\), and \(f(3) = 18 - 36 + 7 = -11\). Same vertex.

Watch out. The most common slip is pulling out \(-9\) instead of \(-18\). Whatever leaves the bracket gets multiplied by the factor in front.

Solve by factoring: \(3x^2 - 5x - 2 = 0\).

Find two numbers that multiply to \(a \times c = -6\) and add to \(-5\). Then split the middle term.
\(x = -\tfrac{1}{3}\) or \(x = 2\)
  1. \(ac = 3(-2) = -6\). Two numbers with product \(-6\) and sum \(-5\): \(-6\) and \(1\).
  2. Split the middle term: \(3x^2 - 6x + x - 2 = 0\).
  3. Group: \(3x(x - 2) + 1(x - 2) = 0\), so \((3x + 1)(x - 2) = 0\).
  4. Set each factor to zero: \(3x + 1 = 0 \Rightarrow x = -\tfrac13\), and \(x - 2 = 0 \Rightarrow x = 2\).

Why it works. If a product is zero, at least one factor must be zero. That only works when one side of the equation is 0.

Watch out. Expand your factors to check: \((3x+1)(x-2) = 3x^2 - 6x + x - 2 = 3x^2 - 5x - 2\). Sign errors in the split are the usual problem.

Use the quadratic formula to solve \(x^2 + 4x - 1 = 0\). Give exact answers in simplest radical form.

\(a = 1,\ b = 4,\ c = -1\). Simplify the root, then divide every term by the denominator.
\(x = -2 \pm \sqrt{5}\)
  1. \(x = \dfrac{-b \pm \sqrt{b^2 - 4ac}}{2a} = \dfrac{-4 \pm \sqrt{16 - 4(1)(-1)}}{2}\).
  2. Discriminant: \(16 + 4 = 20\), so \(x = \dfrac{-4 \pm \sqrt{20}}{2}\).
  3. Simplify the radical: \(\sqrt{20} = \sqrt{4}\sqrt{5} = 2\sqrt5\), so \(x = \dfrac{-4 \pm 2\sqrt5}{2}\).
  4. Divide both terms by 2: \(x = -2 \pm \sqrt5\).

Sense check. \(\sqrt5 \approx 2.24\), so the roots are about \(0.24\) and \(-4.24\). Their average is \(-2\), which is the axis of symmetry \(x = -\tfrac{b}{2a}\).

Watch out. You must divide both terms by 2. Writing \(-2 \pm 2\sqrt5\) is a very common error.

Without solving, how many zeros does \(f(x) = 4x^2 - 12x + 9\) have? What does that tell you about its graph?

Calculate the discriminant \(b^2 - 4ac\).
Exactly one zero. The vertex sits on the \(x\)-axis.
  1. \(D = b^2 - 4ac = (-12)^2 - 4(4)(9) = 144 - 144 = 0\).
  2. \(D = 0\) means one real (double) root.
  3. In fact \(4x^2 - 12x + 9 = (2x - 3)^2\), so the zero is \(x = \tfrac32\) and the vertex is \(\left(\tfrac32, 0\right)\).

The rule. \(D \gt 0\): two zeros. \(D = 0\): one zero (vertex on the axis). \(D \lt 0\): no real zeros.

Watch out. \(b = -12\), and \((-12)^2 = +144\). Squaring a negative is always positive.

For what values of \(k\) does \(kx^2 + 6x + k = 0\) have two distinct real roots?

Two distinct real roots means \(D \gt 0\). Then ask yourself: what happens when \(k = 0\)?
\(-3 \lt k \lt 3\) and \(k \ne 0\)
  1. \(D = 6^2 - 4(k)(k) = 36 - 4k^2\).
  2. Two distinct roots: \(36 - 4k^2 \gt 0 \Rightarrow k^2 \lt 9 \Rightarrow -3 \lt k \lt 3\).
  3. If \(k = 0\) the equation becomes \(6x = 0\). That is linear with one root, so \(k = 0\) must be excluded.

Why it works. The discriminant only describes a quadratic. Before you trust it, make sure \(a \ne 0\).

Watch out. \(k^2 \lt 9\) is not \(k \lt 3\). It is \(-3 \lt k \lt 3\). Test \(k = -5\): \(36 - 100 \lt 0\), so no roots.

A parabola has zeros at \(x = -1\) and \(x = 5\) and passes through \((2, -18)\). Find its equation in standard form. What is special about the point \((2, -18)\)?

Start from factored form \(y = a(x - r)(x - s)\) and use the point to find \(a\).
\(y = 2x^2 - 8x - 10\). The point \((2, -18)\) is the vertex.
  1. Factored form with the zeros: \(y = a(x + 1)(x - 5)\).
  2. Substitute \((2, -18)\): \(-18 = a(3)(-3) = -9a\), so \(a = 2\).
  3. Expand: \(y = 2(x^2 - 4x - 5) = 2x^2 - 8x - 10\).
  4. The axis of symmetry is halfway between the zeros: \(x = \tfrac{-1 + 5}{2} = 2\). The given point has \(x = 2\), so it is the vertex.

Why it works. Zeros fix the shape's position. One more point fixes the stretch \(a\).

Watch out. A zero at \(x = -1\) gives the factor \((x + 1)\), not \((x - 1)\).

Does the line \(y = 2x - 3\) intersect the parabola \(y = x^2 - 4x + 6\)? If so, where?

Set the two right sides equal, move everything to one side, then look at the discriminant.
Yes, at exactly one point: \((3, 3)\). The line is tangent to the parabola.
  1. \(x^2 - 4x + 6 = 2x - 3\).
  2. \(x^2 - 6x + 9 = 0\).
  3. \(D = 36 - 36 = 0\): one point of intersection. Factor: \((x - 3)^2 = 0\), so \(x = 3\).
  4. \(y = 2(3) - 3 = 3\). Check in the parabola: \(9 - 12 + 6 = 3\). ✓

The idea. Solving the system gives a quadratic. Its discriminant counts the intersections: 2, 1 (tangent) or 0.

Watch out. Find \(y\) too. The question asks where, which is a point, not just an \(x\) value.

Find every value of \(k\) for which the line \(y = kx - 1\) is tangent to the parabola \(y = x^2 + 3\). Find the points of tangency.

Tangent means exactly one intersection, so set \(D = 0\).
\(k = 4\), touching at \((2, 7)\); and \(k = -4\), touching at \((-2, 7)\).
  1. \(x^2 + 3 = kx - 1 \Rightarrow x^2 - kx + 4 = 0\).
  2. One intersection: \(D = k^2 - 4(1)(4) = 0 \Rightarrow k^2 = 16 \Rightarrow k = \pm 4\).
  3. \(k = 4\): \(x^2 - 4x + 4 = (x-2)^2 = 0\), so \(x = 2\), \(y = 2^2 + 3 = 7\).
  4. \(k = -4\): \(x^2 + 4x + 4 = (x+2)^2 = 0\), so \(x = -2\), \(y = 7\).

Picture it. Every line \(y = kx - 1\) passes through \((0, -1)\), below the parabola. Two of them just touch it, one on each side. The parabola is symmetric, so the slopes are opposites.

Watch out. \(k^2 = 16\) has two answers. Dropping \(k = -4\) loses half the marks.

A ball is thrown so that its height in metres after \(t\) seconds is \(h(t) = -4.9t^2 + 19.6t + 2\).

(a) What is the maximum height, and when does it happen? (b) When does the ball hit the ground?

(a) The vertex. (b) Solve \(h(t) = 0\) with the quadratic formula and reject any answer that does not make sense.
(a) 21.6 m at \(t = 2\) s. (b) About 4.10 s.
  1. (a) \(t = -\dfrac{b}{2a} = -\dfrac{19.6}{2(-4.9)} = 2\). Then \(h(2) = -4.9(4) + 19.6(2) + 2 = -19.6 + 39.2 + 2 = 21.6\) m.
  2. (b) \(D = 19.6^2 - 4(-4.9)(2) = 384.16 + 39.2 = 423.36\), and \(\sqrt{423.36} \approx 20.576\).
  3. \(t = \dfrac{-19.6 \pm 20.576}{-9.8}\), giving \(t \approx -0.10\) or \(t \approx 4.10\).
  4. Time can't be negative here, so the ball lands at about \(4.10\) s.

Context matters. The math gives two answers. The situation decides which one counts.

Watch out. \(a = -4.9\) is negative, so the denominator \(2a = -9.8\) is negative too. Keep the sign.

A theatre sells 400 tickets at \$12 each. For every \$1 increase in price, 20 fewer tickets sell. What price gives the maximum revenue, and what is that revenue?

Let \(x\) be the number of \$1 increases. Revenue = (price)(tickets sold).
\$16 per ticket, 320 tickets, revenue \$5120.
  1. Price \(= 12 + x\). Tickets \(= 400 - 20x\).
  2. \(R(x) = (12 + x)(400 - 20x)\).
  3. Zeros of \(R\): \(x = -12\) and \(x = 20\). The vertex is halfway: \(x = \tfrac{-12 + 20}{2} = 4\).
  4. Price \(= 12 + 4 = \$16\). Tickets \(= 400 - 80 = 320\). Revenue \(= 16 \times 320 = \$5120\).

Shortcut. Leave \(R\) in factored form. The zeros are easy to read, and the max is at their midpoint, so you never have to expand.

Watch out. \(x = 4\) is the number of increases, not the price. Answer the question that was asked.

Two numbers differ by 10. What are they if their product is as small as possible?

Call them \(x\) and \(x + 10\). The product is a quadratic in \(x\).
\(-5\) and \(5\). Minimum product \(-25\).
  1. \(P(x) = x(x + 10) = x^2 + 10x\). It opens up, so it has a minimum.
  2. Zeros at \(x = 0\) and \(x = -10\), so the vertex is at \(x = -5\).
  3. The numbers are \(-5\) and \(5\), and \(P(-5) = -25\).

Intuition. A negative times a positive is negative. The product is most negative when the two numbers are balanced around 0.

Watch out. Many students assume the answer must be positive numbers. Nothing in the question says so.

Explain why \(f(x) = a(x - h)^2 + k\) has no \(x\)-intercepts when \(a \lt 0\) and \(k \lt 0\). Give a graphical reason and an algebraic one.

Which way does it open, and where is its highest point?
It opens down and its highest point is \(k \lt 0\), so the whole graph is below the \(x\)-axis.
  1. Graphically: \(a \lt 0\) means it opens down, so the vertex \((h, k)\) is the maximum. If the maximum is below the axis (\(k \lt 0\)), every point is.
  2. Algebraically: set \(f(x) = 0\): \((x - h)^2 = -\dfrac{k}{a}\).
  3. \(-k \gt 0\) and \(a \lt 0\), so \(-\dfrac{k}{a} \lt 0\). A square can't be negative, so there's no real solution.

Reuse this. Sign of \(a\) plus sign of \(k\) tells you the number of zeros in seconds. Same signs: none. Opposite signs: two. \(k = 0\): one.

Watch out. “Explain” questions are Communication marks. Use both words and math, as shown.

Find the mistake. A student completed the square like this:

\(f(x) = -x^2 + 6x - 5\)
\(= -(x^2 + 6x) - 5\)
\(= -(x + 3)^2 + 9 - 5\)
\(= -(x + 3)^2 + 4\)

Find the error, fix it, and explain why the final \(k\) still happens to be right.

Check the sign inside the bracket after factoring out \(-1\).
Line 2 should be \(-(x^2 - 6x) - 5\). Correct answer: \(f(x) = -(x - 3)^2 + 4\), vertex \((3, 4)\).
  1. Factoring \(-1\) out of \(-x^2 + 6x\) gives \(-(x^2 - 6x)\). Every sign inside flips.
  2. \(-(x^2 - 6x + 9 - 9) - 5 = -(x - 3)^2 + 9 - 5 = -(x - 3)^2 + 4\).
  3. Check: \(x = -\tfrac{b}{2a} = -\tfrac{6}{-2} = 3\) and \(f(3) = -9 + 18 - 5 = 4\). ✓
  4. The \(k\) value matched by luck. Both versions moved \(+9\) out of the bracket, but the student's vertex \((-3, 4)\) is on the wrong side of the axis.

Habit to build. After completing the square, check \(h\) with \(-\tfrac{b}{2a}\). It takes five seconds.

Watch out. “Find the error” questions often hide a mistake that leads to a partly right answer. Check every line.

Simplify \(\sqrt{72}\).

Find the largest perfect square that divides 72.
\(6\sqrt2\)
  1. Perfect squares that divide 72: 4, 9, 36. The largest is 36.
  2. \(\sqrt{72} = \sqrt{36 \times 2} = \sqrt{36}\,\sqrt{2} = 6\sqrt2\).

Why it works. \(\sqrt{ab} = \sqrt a\,\sqrt b\) for \(a, b \ge 0\).

Watch out. Using 4 first gives \(2\sqrt{18}\), which is not simplest form. Keep going: \(2\sqrt{18} = 2 \cdot 3\sqrt2 = 6\sqrt2\).

Simplify \(3\sqrt{20} - \sqrt{45} + \sqrt5\).

Simplify each radical first. You can only combine like radicals.
\(4\sqrt5\)
  1. \(3\sqrt{20} = 3\sqrt{4}\sqrt5 = 6\sqrt5\).
  2. \(\sqrt{45} = \sqrt9\sqrt5 = 3\sqrt5\).
  3. \(6\sqrt5 - 3\sqrt5 + \sqrt5 = 4\sqrt5\).

Think of it like algebra. \(\sqrt5\) behaves like a variable: \(6y - 3y + y = 4y\).

Watch out. \(\sqrt{20} - \sqrt{45} \ne \sqrt{-25}\). You can't add or subtract the numbers under the root.

Expand and simplify \((2\sqrt3 - \sqrt2)(\sqrt3 + 4\sqrt2)\).

FOIL, then multiply coefficients with coefficients and radicals with radicals.
\(-2 + 7\sqrt6\)
  1. \(2\sqrt3 \cdot \sqrt3 = 2 \cdot 3 = 6\).
  2. \(2\sqrt3 \cdot 4\sqrt2 = 8\sqrt6\).
  3. \(-\sqrt2 \cdot \sqrt3 = -\sqrt6\).
  4. \(-\sqrt2 \cdot 4\sqrt2 = -4 \cdot 2 = -8\).
  5. Combine: \(6 - 8 + 8\sqrt6 - \sqrt6 = -2 + 7\sqrt6\).

Key fact. \(\sqrt a \cdot \sqrt a = a\). That's how the radicals disappear in steps 1 and 4.

Watch out. \(-\sqrt2 \cdot 4\sqrt2\) is \(-8\), not \(-4\sqrt4\) left unsimplified, and not \(+8\).

Which is larger, \(3\sqrt5\) or \(2\sqrt{11}\)? Decide without a calculator.

Move each coefficient inside its root.
\(3\sqrt5\) is larger.
  1. \(3\sqrt5 = \sqrt{9}\sqrt5 = \sqrt{45}\).
  2. \(2\sqrt{11} = \sqrt4\sqrt{11} = \sqrt{44}\).
  3. \(45 \gt 44\), so \(\sqrt{45} \gt \sqrt{44}\).

Why it works. Square roots keep order: if \(a \gt b \ge 0\), then \(\sqrt a \gt \sqrt b\).

Watch out. “3 is bigger than 2” or “11 is bigger than 5” doesn't settle it. You have to combine them.

Describe the transformations that map \(y = \sqrt x\) onto \(y = -2\sqrt{x + 3} + 1\). Sketch using key points, and state the domain and range.

Compare with \(y = a\sqrt{k(x - d)} + c\). Map the points \((0,0), (1,1), (4,2)\).
Vertical stretch by 2, reflection in the \(x\)-axis, left 3, up 1. Domain \(x \ge -3\), range \(y \le 1\).
  1. \(a = -2\): vertical stretch by a factor of 2 and a reflection in the \(x\)-axis.
  2. \(d = -3\): shift left 3. \(c = 1\): shift up 1.
  3. Mapping rule: \((x, y) \to (x - 3,\ -2y + 1)\).
  4. \((0,0) \to (-3, 1)\), \((1,1) \to (-2, -1)\), \((4,2) \to (1, -3)\).
  5. It starts at \((-3, 1)\) and goes down to the right. Domain \(\{x \in \mathbb{R} \mid x \ge -3\}\), range \(\{y \in \mathbb{R} \mid y \le 1\}\).

Order matters. Apply stretches and reflections first, then translations. The mapping rule does this automatically.

Watch out. The reflection flips the range. Without it the range would be \(y \ge 1\).

Describe the transformations of \(y = \sqrt x\) that give \(y = \sqrt{-x + 4}\). State the domain and range.

Factor \(-1\) out of the inside first.
\(y = \sqrt{-(x - 4)}\): reflection in the \(y\)-axis, then shift right 4. Domain \(x \le 4\), range \(y \ge 0\).
  1. Rewrite: \(-x + 4 = -(x - 4)\), so \(y = \sqrt{-(x - 4)}\).
  2. \(k = -1\): reflection in the \(y\)-axis. \(d = 4\): shift right 4.
  3. Mapping: \((x, y) \to (-x + 4,\ y)\). \((0,0) \to (4,0)\), \((1,1) \to (3,1)\), \((4,2) \to (0,2)\).
  4. The graph starts at \((4, 0)\) and goes up to the left. Domain \(x \le 4\), range \(y \ge 0\).

Check the domain directly. The inside must be \(\ge 0\): \(-x + 4 \ge 0 \Rightarrow x \le 4\). Same answer.

Watch out. Reading \(\sqrt{-x + 4}\) as “left 4” is the classic mistake. Always factor out \(k\) before you read \(d\).

Show that \(y = \sqrt{4x}\) and \(y = 2\sqrt x\) have the same graph. What does that tell you about horizontal compressions of root functions?

Use \(\sqrt{ab} = \sqrt a\sqrt b\).
\(\sqrt{4x} = \sqrt4\,\sqrt x = 2\sqrt x\) for \(x \ge 0\). A horizontal compression by \(\tfrac14\) gives the same graph as a vertical stretch by 2.
  1. For \(x \ge 0\): \(\sqrt{4x} = \sqrt4\sqrt x = 2\sqrt x\).
  2. Check a point: at \(x = 1\), \(\sqrt{4} = 2\) and \(2\sqrt1 = 2\). ✓
  3. So the horizontal compression by a factor of \(\tfrac14\) in \(\sqrt{4x}\) produces the same graph as the vertical stretch by 2 in \(2\sqrt x\).

Bigger idea. One graph can be described by different transformations. This only works this neatly because \(4\) is a perfect square. Try \(\sqrt{9x} = 3\sqrt x\).

Watch out. This does not work for every function. \((4x)^2 = 16x^2\), not \(4x^2\).

Find the inverse of \(f(x) = (x - 2)^2 + 1\), \(x \ge 2\). State the domain and range of \(f^{-1}\).

Swap \(x\) and \(y\), solve for \(y\). Which sign of the square root keeps the range correct?
\(f^{-1}(x) = 2 + \sqrt{x - 1}\). Domain \(x \ge 1\), range \(y \ge 2\).
  1. Write \(y = (x - 2)^2 + 1\) and swap: \(x = (y - 2)^2 + 1\).
  2. \((y - 2)^2 = x - 1\), so \(y - 2 = \pm\sqrt{x - 1}\).
  3. The original domain \(x \ge 2\) becomes the inverse's range \(y \ge 2\), so take the \(+\) root: \(y = 2 + \sqrt{x - 1}\).
  4. The domain of \(f^{-1}\) is the range of \(f\): \(x \ge 1\).

Why it works. An inverse swaps inputs and outputs, so domain and range trade places. Its graph is the reflection in \(y = x\).

Watch out. Without the restriction \(x \ge 2\), the inverse would not be a function.

Why must the domain of \(f(x) = x^2\) be restricted before its inverse is a function? Give a restriction that works and the inverse it produces.

Think about the horizontal line test, and try \(f(2)\) and \(f(-2)\).
\(f\) fails the horizontal line test (\(f(2) = f(-2) = 4\)). Restrict to \(x \ge 0\), and then \(f^{-1}(x) = \sqrt x\).
  1. \(f(2) = 4\) and \(f(-2) = 4\). The inverse would have to send 4 to both 2 and \(-2\), so it would not be a function.
  2. Keep only one side of the parabola, \(x \ge 0\). Now each output comes from exactly one input.
  3. Inverse: \(x = y^2,\ y \ge 0 \Rightarrow y = \sqrt x\).
  4. Restricting to \(x \le 0\) also works, and gives \(f^{-1}(x) = -\sqrt x\).

Connection. This is exactly why \(y = \sqrt x\) is only “half” a sideways parabola.

Watch out. The vertical line test checks whether \(f\) is a function. The horizontal line test checks whether its inverse is.

Solve \(\sqrt{x + 7} = x - 5\). Check your answers.

Square both sides, solve the quadratic, then put each answer back into the original equation.
\(x = 9\). (\(x = 2\) is extraneous.)
  1. Square both sides: \(x + 7 = (x - 5)^2 = x^2 - 10x + 25\).
  2. \(x^2 - 11x + 18 = 0 \Rightarrow (x - 2)(x - 9) = 0\), so \(x = 2\) or \(x = 9\).
  3. Check \(x = 2\): left side \(\sqrt9 = 3\), right side \(2 - 5 = -3\). Not equal, so reject.
  4. Check \(x = 9\): \(\sqrt{16} = 4\) and \(9 - 5 = 4\). ✓

Why one answer is fake. Squaring also solves \(-\sqrt{x+7} = x - 5\). The answer \(x = 2\) belongs to that equation. On a graph, the line meets the root curve only once.

Watch out. A square root is never negative. Any answer that makes the right side negative must be rejected.

A radical function \(y = a\sqrt{x - h} + k\) starts at \((2, -3)\) and passes through \((6, 1)\). Find its equation.

The starting point gives \(h\) and \(k\). Use the other point to find \(a\).
\(y = 2\sqrt{x - 2} - 3\)
  1. The endpoint is \((h, k) = (2, -3)\): \(y = a\sqrt{x - 2} - 3\).
  2. Substitute \((6, 1)\): \(1 = a\sqrt{4} - 3 = 2a - 3\).
  3. \(2a = 4 \Rightarrow a = 2\).

Check. \(x = 6\): \(2\sqrt4 - 3 = 4 - 3 = 1\). ✓

Watch out. \(h = 2\) appears as \(x - 2\) inside the root, the opposite sign from the point's coordinate.

Simplify by rationalizing the denominator: (a) \(\dfrac{6}{\sqrt3}\)   (b) \(\dfrac{\sqrt5 + 1}{\sqrt5 - 1}\)

Part (b) goes a step past the usual test questions.

(a) Multiply top and bottom by \(\sqrt3\). (b) Multiply by the conjugate \(\sqrt5 + 1\).
(a) \(2\sqrt3\)   (b) \(\dfrac{3 + \sqrt5}{2}\)
  1. (a) \(\dfrac{6}{\sqrt3}\cdot\dfrac{\sqrt3}{\sqrt3} = \dfrac{6\sqrt3}{3} = 2\sqrt3\).
  2. (b) Multiply by \(\dfrac{\sqrt5 + 1}{\sqrt5 + 1}\). Denominator: \((\sqrt5 - 1)(\sqrt5 + 1) = 5 - 1 = 4\).
  3. Numerator: \((\sqrt5 + 1)^2 = 5 + 2\sqrt5 + 1 = 6 + 2\sqrt5\).
  4. \(\dfrac{6 + 2\sqrt5}{4} = \dfrac{3 + \sqrt5}{2}\).

Why conjugates work. \((a - b)(a + b) = a^2 - b^2\). Squaring removes the root, so the middle terms cancel.

Watch out. \((\sqrt5 + 1)^2 \ne 5 + 1\). Don't forget the middle term \(2\sqrt5\).

Simplify \(\dfrac{x^2 - 9}{x^2 + 5x + 6}\) and state the restrictions.

Factor top and bottom. Find restrictions from the denominator before you cancel.
\(\dfrac{x - 3}{x + 2}\), \(x \ne -2, -3\)
  1. Top: \(x^2 - 9 = (x - 3)(x + 3)\), a difference of squares.
  2. Bottom: \(x^2 + 5x + 6 = (x + 2)(x + 3)\).
  3. Restrictions from the original denominator: \(x \ne -2\), \(x \ne -3\).
  4. Cancel the common factor \((x + 3)\): \(\dfrac{x - 3}{x + 2}\).

Why keep \(x \ne -3\)? The original expression is undefined at \(-3\). Simplifying doesn't change that. The graph has a hole there.

Watch out. If you state restrictions after cancelling, you'll miss \(x \ne -3\).

Simplify \(\dfrac{6x^2 y}{9xy^3}\) and state the restrictions.

Simplify the numbers, then subtract exponents for each variable.
\(\dfrac{2x}{3y^2}\), \(x \ne 0,\ y \ne 0\)
  1. Numbers: \(\tfrac{6}{9} = \tfrac{2}{3}\).
  2. \(\tfrac{x^2}{x} = x\) and \(\tfrac{y}{y^3} = \tfrac{1}{y^2}\).
  3. Result: \(\dfrac{2x}{3y^2}\). The original denominator \(9xy^3\) is zero when \(x = 0\) or \(y = 0\).

Watch out. \(x \ne 0\) stays, even though no \(x\) is left in the simplified denominator.

Simplify \(\dfrac{x^2 - 4}{x^2 + x - 6} \times \dfrac{x + 3}{x + 2}\) and state the restrictions.

Factor everything first, then cancel factors across the multiplication.
\(1\), with \(x \ne -3, -2, 2\)
  1. \(x^2 - 4 = (x - 2)(x + 2)\) and \(x^2 + x - 6 = (x + 3)(x - 2)\).
  2. \(\dfrac{(x - 2)(x + 2)}{(x + 3)(x - 2)} \times \dfrac{x + 3}{x + 2}\).
  3. Restrictions (both denominators): \(x \ne -3,\ 2,\ -2\).
  4. Every factor cancels, leaving \(1\).

Meaning. The expression equals 1 everywhere except at three \(x\) values, where it is undefined. Its graph is the line \(y = 1\) with three holes.

Watch out. When everything cancels, the answer is 1, not 0.

Simplify \(\dfrac{x^2 - 25}{x^2 - 4x} \div \dfrac{x + 5}{x^2}\) and state all restrictions.

Multiply by the reciprocal. The second fraction's numerator becomes a denominator, so it adds a restriction.
\(\dfrac{x(x - 5)}{x - 4}\), \(x \ne -5, 0, 4\)
  1. Factor: \(\dfrac{(x - 5)(x + 5)}{x(x - 4)} \div \dfrac{x + 5}{x^2}\).
  2. Restrictions: \(x \ne 0, 4\) (first denominator), \(x \ne 0\) (second denominator) and \(x \ne -5\), because the divisor \(\tfrac{x+5}{x^2}\) can't be zero.
  3. Multiply by the reciprocal: \(\dfrac{(x - 5)(x + 5)}{x(x - 4)} \times \dfrac{x^2}{x + 5}\).
  4. Cancel \((x + 5)\) and one \(x\): \(\dfrac{x(x - 5)}{x - 4}\).

Why \(x \ne -5\)? At \(x = -5\) you'd be dividing by \(0\). It's easy to miss because \(x + 5\) started on top.

Watch out. This extra restriction is the most-missed mark on division questions.

Simplify \(\dfrac{3}{x} + \dfrac{2}{x + 1}\) and state the restrictions.

The lowest common denominator is \(x(x + 1)\).
\(\dfrac{5x + 3}{x(x + 1)}\), \(x \ne 0, -1\)
  1. LCD \(= x(x + 1)\).
  2. \(\dfrac{3(x + 1)}{x(x + 1)} + \dfrac{2x}{x(x + 1)}\).
  3. \(\dfrac{3x + 3 + 2x}{x(x + 1)} = \dfrac{5x + 3}{x(x + 1)}\).

Watch out. \(\dfrac{3}{x} + \dfrac{2}{x+1} \ne \dfrac{5}{2x + 1}\). You never add denominators.

Simplify \(\dfrac{x}{x^2 - 1} - \dfrac{1}{x - 1}\) and state the restrictions.

Factor \(x^2 - 1\). Put the subtracted numerator in brackets.
\(\dfrac{-1}{(x - 1)(x + 1)}\), \(x \ne \pm 1\)
  1. \(x^2 - 1 = (x - 1)(x + 1)\), so the LCD is \((x - 1)(x + 1)\).
  2. \(\dfrac{x}{(x - 1)(x + 1)} - \dfrac{(x + 1)}{(x - 1)(x + 1)}\).
  3. \(\dfrac{x - (x + 1)}{(x - 1)(x + 1)} = \dfrac{x - x - 1}{(x - 1)(x + 1)} = \dfrac{-1}{(x - 1)(x + 1)}\).

Check with a number. \(x = 2\): \(\tfrac{2}{3} - 1 = -\tfrac13\), and \(\tfrac{-1}{(1)(3)} = -\tfrac13\). ✓

Watch out. The minus applies to the whole numerator \((x + 1)\). Writing \(x - x + 1\) is the classic error.

Simplify \(\dfrac{1}{x - 2} + \dfrac{1}{2 - x}\).

Look closely at \(2 - x\). How is it related to \(x - 2\)?
\(0\), with \(x \ne 2\)
  1. \(2 - x = -(x - 2)\).
  2. So \(\dfrac{1}{2 - x} = -\dfrac{1}{x - 2}\).
  3. \(\dfrac{1}{x - 2} - \dfrac{1}{x - 2} = 0\), for \(x \ne 2\).

Spot it fast. \(a - b\) and \(b - a\) are opposites. Look for them in every rational question.

Watch out. Using \((x - 2)(2 - x)\) as the LCD still works, but it's longer and easy to mess up.

Simplify \(\dfrac{2}{x^2 - x - 6} + \dfrac{3}{x^2 - 9}\) and state the restrictions.

Factor both denominators. They share one factor. The LCD uses each different factor once.
\(\dfrac{5x + 12}{(x - 3)(x + 2)(x + 3)}\), \(x \ne 3, -2, -3\)
  1. \(x^2 - x - 6 = (x - 3)(x + 2)\) and \(x^2 - 9 = (x - 3)(x + 3)\).
  2. LCD \(= (x - 3)(x + 2)(x + 3)\).
  3. \(\dfrac{2(x + 3) + 3(x + 2)}{(x - 3)(x + 2)(x + 3)}\).
  4. Numerator: \(2x + 6 + 3x + 6 = 5x + 12\).

Check. \(5x + 12\) doesn't share a factor with the denominator, so it's fully simplified.

Watch out. Multiplying the two denominators together gives \((x - 3)^2\). That works but makes the algebra harder. Use the LCD.

Simplify \(\dfrac{2x^2 + 7x + 3}{4x^2 - 1}\) and state the restrictions.

Top: decompose with \(ac = 6\). Bottom: difference of squares.
\(\dfrac{x + 3}{2x - 1}\), \(x \ne \pm\tfrac12\)
  1. \(2x^2 + 7x + 3\): \(ac = 6\), and 6 and 1 add to 7. So \(2x^2 + 6x + x + 3 = 2x(x + 3) + 1(x + 3) = (2x + 1)(x + 3)\).
  2. \(4x^2 - 1 = (2x - 1)(2x + 1)\).
  3. Restrictions: \(2x - 1 \ne 0\) and \(2x + 1 \ne 0\), so \(x \ne \tfrac12, -\tfrac12\).
  4. Cancel \((2x + 1)\): \(\dfrac{x + 3}{2x - 1}\).

Watch out. Restrictions are values of \(x\). From \(2x - 1 \ne 0\) you get \(x \ne \tfrac12\), not \(x \ne 1\).

Simplify \(\dfrac{4 - x}{x^2 - 16}\) and state the restrictions.

\(4 - x = -(x - 4)\).
\(-\dfrac{1}{x + 4}\), \(x \ne \pm 4\)
  1. \(x^2 - 16 = (x - 4)(x + 4)\). Restrictions: \(x \ne 4, -4\).
  2. \(4 - x = -(x - 4)\).
  3. \(\dfrac{-(x - 4)}{(x - 4)(x + 4)} = -\dfrac{1}{x + 4}\).

Check. \(x = 0\): \(\tfrac{4}{-16} = -\tfrac14\), and \(-\tfrac{1}{4}\). ✓

Watch out. Cancelling \(4 - x\) with \(x - 4\) as if they were equal gives \(+\tfrac{1}{x + 4}\), which has the wrong sign.

Write a rational expression that simplifies to \(\dfrac{x + 1}{x - 4}\) and has restrictions \(x \ne 4\) and \(x \ne -2\). Give it in expanded form.

Multiply top and bottom by the same factor. Which factor creates the restriction \(x \ne -2\)?
\(\dfrac{x^2 + 3x + 2}{x^2 - 2x - 8}\) (other answers are possible)
  1. To get \(x \ne -2\), the denominator needs a factor \((x + 2)\). Multiply top and bottom by it: \(\dfrac{(x + 1)(x + 2)}{(x - 4)(x + 2)}\).
  2. Expand the top: \(x^2 + 3x + 2\). Expand the bottom: \(x^2 - 2x - 8\).
  3. Check: factoring gives back \(\dfrac{(x + 1)(x + 2)}{(x - 4)(x + 2)}\), which simplifies to \(\dfrac{x + 1}{x - 4}\), \(x \ne 4, -2\). ✓

Why this is a great question. It runs simplifying backwards. If you can build one, you understand where restrictions come from.

Watch out. Multiplying only the denominator changes the value of the expression. Always multiply top and bottom.

Is \(f(x) = \dfrac{x^2 - 4}{x - 2}\) the same function as \(g(x) = x + 2\)? Explain, and describe how their graphs differ.

Try \(x = 2\) in both.
No. They're equal for every \(x \ne 2\), but \(f(2)\) is undefined. The graph of \(f\) is the line \(y = x + 2\) with a hole at \((2, 4)\).
  1. \(f(x) = \dfrac{(x - 2)(x + 2)}{x - 2} = x + 2\), for \(x \ne 2\).
  2. \(g(2) = 4\), but \(f(2) = \tfrac{0}{0}\), which is undefined.
  3. So \(f\) and \(g\) have different domains, which makes them different functions.
  4. The hole is where \(g\) would be: \((2, 4)\).

Big idea. Two functions are equal only if they have the same domain and the same outputs. This is why restrictions matter.

Watch out. Graphing calculators often don't show the hole. Don't trust the picture alone.

Simplify \(\dfrac{1 - \frac{1}{x}}{1 - \frac{1}{x^2}}\) and state the restrictions.

A step past the usual test questions, but it uses only what you know.

Write the top and the bottom as single fractions first, then divide.
\(\dfrac{x}{x + 1}\), \(x \ne 0, 1, -1\)
  1. Top: \(1 - \tfrac1x = \tfrac{x - 1}{x}\).
  2. Bottom: \(1 - \tfrac{1}{x^2} = \tfrac{x^2 - 1}{x^2} = \tfrac{(x - 1)(x + 1)}{x^2}\).
  3. Divide by multiplying by the reciprocal: \(\dfrac{x - 1}{x} \times \dfrac{x^2}{(x - 1)(x + 1)} = \dfrac{x}{x + 1}\).
  4. Restrictions: \(x \ne 0\) (inside fractions), and the bottom can't be 0, so \(x \ne \pm 1\).

Watch out. \(x \ne 1\) disappears from the final form. That's exactly why you list restrictions from the start.

Find the mistake. A student wrote \(\dfrac{x + 3}{x + 6} = \dfrac{3}{6} = \dfrac12\) by “cancelling the \(x\)'s.” Explain what's wrong, and prove it with a number.

Can you cancel terms that are being added? Try \(x = 3\).
You can only cancel common factors, never terms joined by \(+\) or \(-\). At \(x = 3\), the expression is \(\tfrac{6}{9} = \tfrac23\), not \(\tfrac12\).
  1. \(x + 3\) and \(x + 6\) have no common factor, so \(\dfrac{x + 3}{x + 6}\) is already in simplest form (\(x \ne -6\)).
  2. Test \(x = 3\): \(\tfrac{3 + 3}{3 + 6} = \tfrac69 = \tfrac23 \ne \tfrac12\).
  3. Cancelling works only on multiplication: \(\dfrac{x \cdot 3}{x \cdot 6} = \dfrac12\) (for \(x \ne 0\)).

Rule of thumb. Factor first. If it isn't a factor of the entire top and the entire bottom, it can't cancel.

Watch out. Plugging in a number is the fastest way to test any simplification you're unsure of.

Find the exact \(x\)-intercepts and the equation of the axis of symmetry of \(y = x^2 - 2x - 1\).

It doesn't factor. Use the quadratic formula and simplify the radical.
\(x = 1 \pm \sqrt2\). Axis of symmetry \(x = 1\).
  1. \(x = \dfrac{2 \pm \sqrt{4 + 4}}{2} = \dfrac{2 \pm \sqrt8}{2}\).
  2. \(\sqrt8 = 2\sqrt2\), so \(x = \dfrac{2 \pm 2\sqrt2}{2} = 1 \pm \sqrt2\).
  3. The axis is the average of the zeros: \(\tfrac{(1 + \sqrt2) + (1 - \sqrt2)}{2} = 1\).

Links two units. Quadratics produce radicals, and simplifying radicals is what makes the answer exact.

Watch out. “Exact” means leave \(\sqrt2\). Writing \(2.41\) and \(-0.41\) loses marks.

A rectangle has area \(\dfrac{x^2 + 7x + 12}{x - 2}\) and width \(\dfrac{x + 3}{x^2 - 4}\). Find its length in simplest form and state the restrictions.

Length = area ÷ width. Factor everything.
\((x + 4)(x + 2) = x^2 + 6x + 8\), with \(x \ne 2, -2, -3\)
  1. \(\text{Length} = \dfrac{(x + 3)(x + 4)}{x - 2} \div \dfrac{x + 3}{(x - 2)(x + 2)}\).
  2. Multiply by the reciprocal: \(\dfrac{(x + 3)(x + 4)}{x - 2} \times \dfrac{(x - 2)(x + 2)}{x + 3}\).
  3. Cancel \((x + 3)\) and \((x - 2)\): \((x + 4)(x + 2) = x^2 + 6x + 8\).
  4. Restrictions: \(x \ne 2\) and \(x \ne -2\) from the denominators, and \(x \ne -3\) because the width can't be 0.

Check by multiplying. Length × width should give back the area: \((x+4)(x+2) \cdot \tfrac{x+3}{(x-2)(x+2)} = \tfrac{(x+3)(x+4)}{x-2}\). ✓

Watch out. \(x \ne -3\) comes from the divisor's numerator. That's the same trap as in division questions.

Find the exact zeros of \(f(x) = 2(x - 3)^2 - 10\).

In vertex form, isolate the square and take the square root of both sides.
\(x = 3 \pm \sqrt5\)
  1. \(2(x - 3)^2 - 10 = 0 \Rightarrow (x - 3)^2 = 5\).
  2. \(x - 3 = \pm\sqrt5\), so \(x = 3 \pm \sqrt5\).

Fast route. From vertex form you never need the quadratic formula. Undo the operations in reverse order.

Watch out. Taking a square root needs \(\pm\). Without it you lose a zero.
